# Claude Code に渡すプロンプト集

上から順に、1つずつ Claude Code に貼り付けて使う。
1つの段階が終わり、エディタと HMD で動作を確かめてから次へ進む。段階の切り替わりで会話をリセットすると、余計な文脈が残らず精度が上がる。

---

## 0. 最初の1回：読み込みと計画

```
CLAUDE.md と docs/SPEC.md を読んでください。
次に Packages/manifest.json と Assets/ の中身を確認し、
1) 入っている Unity・XRI・OpenXR のバージョン
2) 仕様を実装するうえで足りないパッケージや素材
3) SPEC の中で曖昧・矛盾していると思う点
を報告してください。コードはまだ書かないでください。
```

---

## 1. 土台：設定・割り当て・ログ

```
SPEC の 2章と 6章を実装してください。
- ExperimentConfig（ScriptableObject）：SPEC の [ ] の値をすべて持たせる。初期値は SPEC の値
- ParticipantAssignment：id から group・授業順・条件順を返す純粋な static クラス。4通りすべての EditMode テストを付ける
- participants.csv の読み込みと、未登録番号の判定
- EventLogger と HeadLogger：SPEC 6章の列どおりに CSV を書く。出来事ごとにフラッシュする
先に作るファイルとクラスの一覧を出して、私の了承を得てから実装してください。
```

---

## 2. 数式のロジックとテスト

```
SPEC 4章の式を Assets/Scripts/Core/ に純粋な static 関数として実装し、EditMode テストを付けてください。
- 注視角 θ（f, d から度で返す）と、θth 以内かの判定
- 再配置位置 p_new = p_h + D·f/|f|
- イージング e(t) = 3t² − 2t³（e(0)=0, e(1)=1, e'(0)=e'(1)=0 をテストで確認）
- 引き寄せ位置 p(t)
- 拡大率 s = 2D·tan(φ/2)/w（φ は度で受け取る）
- Ttotal の計算（観察フェーズの有無を含む）
テストでは手計算できる値（例：f と d が直交なら 90°）を使ってください。
```

---

## 3. 部品操作と授業の進行（HDD の最小版）

```
SPEC 3章と 5.1 を実装し、HDD の授業を最小限で動かせるようにしてください。
- LessonData / StageData（ScriptableObject）と、それを順に進める LessonController（状態遷移は SPEC 3章のとおり）
- PartInteraction：説明音声の間は掴めない、受付中は掴める、強調中は掴めない、を切り替える
- PartSocket：正しい部品だけ受け付け、向きのずれ [15]° 以内で吸着。socket_ok をログに記録
- まだ強調は入れない。要点のパートは「強調の代わりに何もしない」仮の処理でよい
- テスト用に、立方体などの仮の部品3つで動く HDD_Test.asset と、シーンを組み立てる Editor メニューを作る
最後に、私がエディタと HMD で確認する手順を書いてください。
```

---

## 4. 学習者パネルと実験者の操作

```
SPEC 5.2 と 5.3 を実装してください。
- VR 内の学習者パネル（リセット・ヒント）。ヒントは正しい場所を光らせ、回数をログに記録
- PC キーボードでの実験者操作（スキップ・一時停止／再開・中断）
- useAutoTimers が true のときだけ、60秒でヒント・120秒で自動完了
- HMD を外した・トラッキングを失ったときの自動一時停止（使える API をバージョンに合わせて調べて提案してから実装）
```

---

## 5. 注視判定と再配置

```
SPEC 4.1 と 4.2 を実装してください（GazeJudge, Relocator）。
- 要点のパートで操作が完了したら判定を始める
- θ ≤ θth が t_hold 続いたら gaze_ok、t_timeout で再配置、N 回を超えたら gaze_fail でテロップのみ
- 再配置で他の部品と重なる場合は 0.1 m ずつ奥へ
- 判定中の θ を head.csv に出す
- エディタ上で確認できるよう、θ と状態を表示するデバッグ用の表示（ビルドでは消える）を付ける
```

---

## 6. 空間的強調とテロップ

```
SPEC 4.3〜4.5 を実装してください（EmphasisController, TelopView）。
- 条件による分岐は EmphasisController の中だけ。条件1は Ttotal 待つ、条件2は 引き寄せ→拡大→回転→（観察）→復帰 を直列に実行
- 開始前に元の位置・回転・大きさを保存し、一時停止されたらすぐ元に戻せるようにする
- 各段階の開始を emphasis_phase としてログに記録
- テロップは World Space Canvas ＋ TextMeshPro で部品の上に出し、受講者の方を向かせる。日本語フォントアセットがなければ作り方を教えて
- 説明音声は 2D、操作音は 3D
条件1と条件2の合計時間が一致することを EditMode テストで確認してください。
```

---

## 7. 教室の取り込み

```
Polycam でスキャンした部屋（glTF）を取り込みたいです。
- glTFast（com.unity.cloud.gltfast）の導入方法
- Quest 3 単体で重くならないためのポリゴン削減とテクスチャの目安
- スキャンに焼き込まれた明るさと、部品の照明を合わせる方法
を、私が作業する手順として書いてください。コード側で必要なもの（床の高さ合わせ、当たり判定など）があれば実装してください。
```

---

## 8. HMD の授業と全体の通し

```
HMD の授業データ（HMD.asset）を作れる状態にし、2本の授業を SPEC 1章の流れで通せるようにしてください。
- ExperimentManager：番号入力 → 割り当て → 練習 → 1本目 → 「HMD を外してテストへ」 → 休憩後に2本目 → 終了
- 練習用の課題（練習用の部品を掴んで置く。3回目で失敗したら実験者が補助）
- 実機（Quest 3）へのビルド手順と、ログを PC に取り出す手順（adb など）
```

---

## 9. 分析スクリプト

```
SPEC 7章の分析を analysis/ に Python で作ってください。
- 入力：logs/<id>/events.csv、テストの採点結果 CSV、質問紙 CSV（列の形を先に提案して）
- 出力：条件別の要約表、dz・gz・t・p、図（各参加者の条件1→条件2を線で結んだ図）
- SSQ と NASA-TLX(WWL) の採点表は analysis/tables/ に私が原典から用意します。表の形式だけ決めてください
- まず架空のデータを20人分作って、スクリプトが最後まで動くことを確認してください（架空データは analysis/dummy/ に置き、本番データと混ぜない）
```

## 困ったときに使う短いプロンプト

- 動かない：`エディタのコンソールにこのエラーが出ました。原因と直し方を教えて：<エラーを貼る>`
- 仕様を変えたい：`SPEC の <項目> を <変更内容> に変えたいです。影響する箇所を洗い出してから、SPEC とコードの両方を直してください`
- 進み具合の確認：`SPEC の各章について、実装済み・未実装・テスト済みを表にしてください`
- 予備実験の前：`予備実験で値を調整しやすいように、ExperimentConfig の値をエディタから変えられるか、ログに必要な情報が全部出ているかを点検してください`
